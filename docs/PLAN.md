# Material Agent 开发计划

## 目标
完善 Agent 能力 + RAG 增强，生产级实现

## 阶段一：Agent 能力增强

### 1.1 多模型支持
- [ ] 抽象 ChatModel 接口，支持 Kimi/OpenAI/Claude/Ollama
- [ ] 配置化模型选择（application.yml）
- [ ] 模型熔断器（失败后自动切换）
- [ ] 模型请求指标收集

### 1.2 Function Calling
- [ ] 使用 Spring AI @Tool 注解定义工具
- [ ] 自动生成工具 Schema
- [ ] 工具执行结果自动注入 LLM

### 1.3 对话历史管理
- [ ] ChatSession 完善（保存/加载历史）
- [ ] 历史压缩（摘要式摘要）
- [ ] 会话超时管理

### 1.4 Agent 增强
- [ ] ReAct 循环优化（加入反思步骤）
- [ ] Agent 状态机（运行中/完成/失败）
- [ ] 执行超时控制
